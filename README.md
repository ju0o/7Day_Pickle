# http://localhost:8080

## 🎯 구축 완료 핵심 기능 (v0.1 ~ v0.8.4)

1. **소셜 바이럴 해시태그 & 다중 태그 엔진 (`src/engine/tags.js`) [DAY 3 4회차 신규]**:
   - 고민 키워드·카테고리·성향 기반 자동 해시태그(#) 추천 (한/영 30+ 바이럴 키워드 매핑)
   - 결과 카드 인터랙티브 태그 칩스 및 원클릭 클립보드 복사 토스트
   - X(Twitter) / Threads 포스팅 인텐트 & 판결문 텍스트 클립보드 자동 해시태그 첨부
   - 입력 섹션 인기 고민 태그(Trending Chips) 7종 원클릭 템플릿 입력 연동
   - 4대 캔버스 공유 카드 하단 해시태그 각인 연동
2. **AI 심판관 커스텀 성향 튜너 (`src/engine/bias.js`) [DAY 3 3회차 신규]**:
   - 4대 판결 성향 프리셋: ⚖️ 밸런스(기본 균등 토론) / 🧠 극단적 이성파(Dr. Logic 80% 브레이크&절제) / ⚡ 도파민 풀악셀(Captain Vibe 80% 직진&YOLO) / 💀 현실 팩폭러(Mr. Fact 80% 잔고&후회 팩폭)
   - 이성 vs 본능 미세 조율 슬라이더 (0~100%) 및 LocalStorage 영구 보존
   - 판결 결과 및 SNS 공유 카드에 판결 성향 실시간 각인 & 한/영 다국어 완벽 지원
2. **나의 결정 DNA & 통계 인사이트 대시보드 (`src/analytics/stats.js`) [DAY 3 2회차 신규]**:
   - 4대 카테고리(지름신·커리어·연애·일상) 누적 결정 분포 통계 및 네온 프로그레스 바 차트
   - 3대 KPI 카드 (총 누적 판결 수, 최다 고민 분야, 최다 선고 단어 빈도 분석)
   - 결정 휴리스틱 기반 '나의 결정 DNA 페르소나' (철벽 방어 자산가, 돌격형 야망가, 도파민 액션 빌더, 올라운드 전략가 등 6종) 자동 진단
   - 헤더 📊 분석 모달 연동 및 한/영 실시간 다국어 지원
2. **오프라인 PWA 서비스워커 캐싱 & 홈 화면 설치(A2HS) 엔진 (`sw.js`, `src/pwa/installPrompt.js`) [DAY 3 1회차 신규]**:
   - `sw.js` App Shell 프리캐싱 및 Stale-While-Revalidate 캐싱 전략 탑재 (오프라인 모드 100% 작동)
   - 모바일 브라우저 네이티브 설치 프롬프트(`beforeinstallprompt`) 후킹 및 독립 실행(Standalone) 감지
   - iOS 사파리(Safari) 전용 3단계 홈 화면 추가 가이드 시각 모달 완비 (공유버튼 ➔ 홈 화면에 추가 ➔ 완료)
   - 헤더 실시간 오프라인 상태 알림 뱃지(`⚡ 오프라인 가동`) 및 한/영 다국어 연동
2. **3초 의사결정 판결 알고리즘 (`src/engine/verdict.js`)**:
   - 4대 카테고리(지름신, 커리어/이직, 연애/인간관계, 일상/루틴) 자동 감지
   - 3대 AI 심판관(이성 닥터 로직, 행동 캡틴 바이브, 현실 미스터 팩트)의 팩트 대립 연출
   - 단 하나의 단어(One Word) 선고 및 촌철살인 펀치라인 도출
2. **원클릭 SNS 공유 인텐트 & 텍스트 클립보드 복사기 (`src/share/intentShare.js`) [DAY 2 5회차 신규]**:
   - 𝕏 (Twitter) Web Intent 원클릭 포스팅 (판결문, 선고, 여론 지지율, 해시태그 및 URL 자동 주입)
   - 🧵 스레드 (Threads) Intent 원클릭 포스팅 연동
   - 📋 판결문 마크다운 포맷팅 클립보드 원클릭 복사기 & 실시간 완료 토스트
   - 📱 Web Share API (`navigator.share`) 기반 모바일 시스템 공유 시트 대응
3. **글로벌 다국어 (한국어 / 영어) 실시간 토글 엔진 (`src/i18n/translations.js`) [DAY 2 4회차 신규]**:
   - 헤더 `KR / EN` 원클릭 토글 및 LocalStorage 언어 설정 영구 보존
   - 16종 글로벌 영문 고민 프리셋(피자, 아이폰, 스타트업 이직, 전연인 텍스트 등) 탑재
   - 영문 질문 입력 시 영문 펀치라인 및 영문 3심판관 총평 자동 선고 파이프라인
   - 전체 UI(제목, 카테고리 탭, 입력창, 투표, 공유 버튼 등) 무새로고침 즉시 번역
4. **4대 커스텀 판결 카드 비주얼 테마 스타일러 (`src/canvas/cardGenerator.js`) [DAY 2 3회차 신규]**:
   - ⚡ **사이버 네온 (Cyber)**: 딥 다크 그리드 + 카테고리 네온 글로우 + 코너 프레임
   - 🖤 **미니멀 블랙 (Minimal)**: 순수 피치 블랙 + 1px 모노크롬 와이어프레임 + 볼드 스위스 타이포
   - 📜 **고전 법정 (Parchment)**: 고문서 양피지 질감 + 세리프 활자체 + 붉은 왁스 인장(Red Wax Seal) 도장 각인
   - 👾 **8비트 아케이드 (Retro 8-Bit)**: 브라운관 CRT 스캔라인 + 형광 인광 녹색 + 픽셀 레트로 프레임
   - 1:1 피드(1080px) 및 9:16 스토리 규격 실시간 테마 선택 및 즉시 다운로드
5. **시민 배심원단 여론 투표 시뮬레이터 (`src/engine/voting.js`) [DAY 2 2회차 신규]**:
   - 질문과 판결 기반 결정론적(Deterministic) 여론 통계 산출 (총 850 ~ 3,250명 참여)
   - "👍 완전 인정" vs "👎 결사 반대" 원클릭 투표 및 네온 프로그레스 게이지 애니메이션
   - LocalStorage 기반 사용자 투표 상태 영구 보존 및 실시간 여론 반영
   - SNS 공유 카드에 시민 배심원단 여론 지지율 스탬프 각인 연동
6. **4대 사운드 테마 & 햅틱 진동 피드백 (`src/audio/sound.js`) [DAY 2 1회차 신규]**:
   - 🔨 **법정 (Court)**: 묵직한 원목 법봉 저음 타격
   - ⚡ **사이버 (Cyber)**: 날카로운 레이저 블래스트 & 고주파 신스 글리치
   - 🔔 **미니멀 (Minimal)**: 528Hz 솔페지오 싱잉볼 & 맑은 차임 여운
   - 👾 **8비트 (8-Bit)**: 패미컴 아케이드 점프 & 보스 폭발 사운드
   - 모바일 기기 판결 선고 순간 묵직한 손맛 햅틱 진동 연출 (`navigator.vibrate`)
7. **Canvas 네온 파티클 폭죽 버스트 (`src/fx/particles.js`) [DAY 2 1회차 신규]**:
   - 선고 순간 카테고리 테마 색상의 네온 스파크 파티클 50개가 사방으로 팡 터지는 시각적 카타르시스
8. **🎲 랜덤 고민 셔플러 & 모바일 스와이프 제스처 [DAY 2 1회차 신규]**:
   - 🎲 버튼 클릭 시 16개 프리셋 중 무작위 고민 자동 타이핑
   - 모바일 화면 좌우 스와이프로 5대 카테고리 탭 즉시 전환
9. **로컬 퍼스트 판결 보관함 모달 & URL 공유 (`src/storage/history.js`)**:
   - LocalStorage 기반 최근 판결 영구 보관, 모달 뷰어를 통한 과거 판결 재열람/삭제/이미지 재발급
   - Base64 URL Fragment 해시로 서버 없이 판결 상태 복사 및 전송
10. **원클릭 배포 가이드 & 소셜 메타 태그 (`docs/DEPLOYMENT_GUIDE.md`)**:
   - 빌드 과정 없는 네이티브 GitHub Pages 배포 가이드 완비
   - Open Graph 및 Twitter Card 소셜 메타 태그, PWA 매니페스트 장착
