## 2. PRD (제품 요구사항 명세)

### 타깃 사용자 및 해결할 문제
- **타깃 페르소나:** "이거 살까 말까?", "이직 준비 시작할까?", "고백할까 접을까?", "야식 먹을까 말까?" 끝없이 결정을 미루는 2030 세대 및 1인 빌더.
- **핵심 문제:** 선택지가 많을수록 뇌는 결정을 유예하고 피로가 쌓임(결정 피로 증후군). 길고 지루한 설명 대신, 강력한 한 방의 충격 요법이 필요함.
- **제품의 해법:** 고민 문장을 입력하면 3인의 가상 심판관이 1초씩 팩트 난상토론을 거친 뒤, 최종 선고를 **오직 하나의 단어(One Word)**와 촌철살인 펀치라인으로 내림.

## 3. 핵심 기능 및 사용자 흐름 (User Flow)

1. **[0초] 진입:** 복잡한 회원가입이나 튜토리얼 없이 다크 네온 테마의 중앙 입력창으로 직행.
2. **[1초] 입력:** 고민 질문 입력 (예: "새벽 2시인데 컵라면 물 올릴까?"), 🎲 랜덤 고민 셔플러 원클릭, 또는 4대 프리셋(지름신, 연애/인간관계, 커리어/이직, 일상/루틴) 선택. 모바일 화면 좌우 스와이프로 카테고리 즉시 전환.
3. **[심판 성향 조율]:** ⚖️ 성향 튜너로 이성(닥터 로직 80%) / 도파민(캡틴 바이브 80%) / 현실 팩폭(미스터 팩트 80%) 가중치 미세 조율.
4. **[2초] 심판 연출:**
   - 🧠 이성 심판관: 데이터와 논리로 반박
   - ⚡ 행동 심판관: 속도와 본능으로 반박
   - 💀 현실 심판관: 냉소적 통장/미래 팩트 폭격
5. **[3초] 최종 선고 (One Word Verdict):** 화면 암전 후 네온 플래시 + 4대 테마 사운드(법정/사이버/미니멀/8비트) + 햅틱 손맛 진동 + 캔버스 네온 파티클 폭죽과 함께 단 하나의 단어 선고 (예: **`STOP`**, **`EAT`**, **`RUN`**, **`BUY`**).
6. **[공유 & 보관]:**
   - 1초 인스타그램 스토리 / 스레드 / X 최적화 규격 판결 카드 PNG 자동 생성 및 다운로드 (4대 카드 스타일러 & 여론 스탬프 & 성향 뱃지 각인).
   - X(Twitter) / Threads 원클릭 바이럴 포스팅 인텐트 & 판결문 텍스트 클립보드 복사.
   - 로컬 보관함에 나의 판결 기록 영구 보존 & 나의 결정 DNA 대시보드 통계 진단.

## 4. 기술 스택과 아키텍처

- **프론트엔드 코어:** HTML5, Modern ES6+ Modules (빌드 의존성 제로, 무중단 즉시 구동)
- **스타일링 & 비주얼:** Tailwind CSS + Custom Neon Cyberpunk Theme + Lucide Icons
- **캔버스 그래픽스 & FX:** HTML5 Canvas 2D API (4대 커스텀 테마 판결 카드 생성기 + 네온 파티클 폭죽 버스트 엔진)
- **오디오 & 햅틱 피드백:** Web Audio API (4대 사운드 테마 신디사이저: Court, Cyber, Minimal, 8-Bit) + Vibration API
- **성향 조율 엔진:** `JudgeBiasTuner` (이성/도파민/현실 4대 모드 & 0~100% 슬라이더 가중치 연산)
- **오프라인 & PWA:** Service Worker (Stale-While-Revalidate App Shell 프리캐싱) + A2HS 네이티브 인스톨러
- **상태 관리 & 지속성:** Local-first (LocalStorage) + URL Hash/Query State Serialization
- **배포 인프라:** GitHub Pages (정적 호스팅, 서버 비용 0원, 무중단 가동)
- **검증 & 테스트:** Python 3.12 기반 단위 테스트 및 HTML DOM/정적 자산 무결성 자동화

### 📅 DAY 3 (2026-11-10) — 3회차 (누적 13회차)
- **선택한 작업:** AI 심판관 커스텀 성향 튜너(Judge Bias Tuner) 엔진 구축, 4대 성향 프리셋(밸런스·이성파·도파민·팩폭러) 및 이성 vs 본능 미세 조율 슬라이더 탑재, 판결 결과 및 SNS 공유 카드 성향 뱃지 실시간 각인 연동 (v0.8.3).
- **작업 이유:** 사용자가 처한 고민의 맥락에 따라 "지금은 충동을 말려줄 차가운 이성이 필요하다", "등 떠밀어줄 도파민과 용기가 필요하다", 또는 "현실 팩폭으로 뼈를 맞고 싶다"처럼 원하는 심판의 톤앤매너가 판이하게 다르므로, 3인의 심판관 가중치를 자유롭게 조율하여 개인 맞춤형 의사결정 카타르시스를 제공하기 위함.
- **실제 변경 내용:**
  - `src/engine/bias.js` (신규): `JudgeBiasTuner` 클래스 및 4대 성향 프리셋(`balanced`, `rational` Dr. Logic 80%, `vibe` Captain Vibe 80%, `realist` Mr. Fact 80%) 정의. 슬라이더(0~100%) 값에 따른 동적 성향 맵핑 및 LocalStorage(`oneword_judge_bias`) 영구 저장 파이프라인 완성.
  - `src/engine/verdict.js`: `evaluate()` 메서드에 `biasMode` 파라미터 결합. 이성 모드 시 충동 억제(DROP, HOLD, WAIT, PASS, SLEEP), 도파민 모드 시 무조건 직진(BUY, RUN, GO, EAT, START), 팩폭 모드 시 냉혹한 현실(CHECK, ENDURE, BLOCK, WAKE) 등 4대 카테고리별 성향 맞춤 단어 및 펀치라인 실시간 도출.
  - `src/canvas/cardGenerator.js`: 4대 캔버스 테마(사이버, 미니멀, 고전법정, 8비트) 렌더러에 선택된 심판 성향 뱃지(`⚖️ 밸런스 심판`, `⚡ 도파민 풀악셀`, `🧠 이성/절제 모드`, `💀 현실 팩폭 모드`) 자동 각인 연동.
