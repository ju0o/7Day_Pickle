## 2. PRD (제품 요구사항 명세)

### 타깃 사용자 및 해결할 문제
- **타깃 페르소나:** "이거 살까 말까?", "이직 준비 시작할까?", "고백할까 접을까?", "야식 먹을까 말까?" 끝없이 결정을 미루는 2030 세대 및 1인 빌더.
- **핵심 문제:** 선택지가 많을수록 뇌는 결정을 유예하고 피로가 쌓임(결정 피로 증후군). 길고 지루한 설명 대신, 강력한 한 방의 충격 요법이 필요함.
- **제품의 해법:** 고민 문장을 입력하면 3인의 가상 심판관이 1초씩 팩트 난상토론을 거친 뒤, 최종 선고를 **오직 하나의 단어(One Word)**와 촌철살인 펀치라인으로 내림.

## 3. 핵심 기능 및 사용자 흐름 (User Flow)

1. **[0초] 진입:** 복잡한 회원가입이나 튜토리얼 없이 다크 네온 테마의 중앙 입력창으로 직행.
2. **[1초] 입력:** 고민 질문 입력 (예: "새벽 2시인데 컵라면 물 올릴까?"), 🎲 랜덤 고민 셔플러 원클릭, 또는 4대 프리셋(지름신, 연애/인간관계, 커리어/이직, 일상/루틴) 선택. 모바일 화면 좌우 스와이프로 카테고리 즉시 전환.
3. **[2초] 심판 연출:**
   - 🧠 이성 심판관: 데이터와 논리로 반박
   - ⚡ 행동 심판관: 속도와 본능으로 반박
   - 💀 현실 심판관: 냉소적 통장/미래 팩트 폭격
4. **[3초] 최종 선고 (One Word Verdict):** 화면 암전 후 네온 플래시 + 4대 테마 사운드(법정/사이버/미니멀/8비트) + 햅틱 손맛 진동 + 캔버스 네온 파티클 폭죽과 함께 단 하나의 단어 선고 (예: **`STOP`**, **`EAT`**, **`RUN`**, **`BUY`**).
5. **[공유 & 보관]:**
   - 1초 인스타그램 스토리 / 스레드 / X 최적화 규격 판결 카드 PNG 자동 생성 및 다운로드.
   - 서버 없이 판결 상태를 포함하는 Base64 URL 복사 공유.
   - 로컬 보관함에 나의 판결 기록 영구 보존.

## 4. 기술 스택과 아키텍처

- **프론트엔드 코어:** HTML5, Modern ES6+ Modules (빌드 의존성 제로, 무중단 즉시 구동)
- **스타일링 & 비주얼:** Tailwind CSS + Custom Neon Cyberpunk Theme + Lucide Icons
- **캔버스 그래픽스 & FX:** HTML5 Canvas 2D API (고해상도 판결 카드 생성기 + 네온 파티클 폭죽 버스트 엔진)
- **오디오 & 햅틱 피드백:** Web Audio API (4대 사운드 테마 신디사이저: Court, Cyber, Minimal, 8-Bit) + Vibration API
- **상태 관리 & 지속성:** Local-first (LocalStorage) + URL Hash/Query State Serialization
- **배포 인프라:** GitHub Pages (정적 호스팅, 서버 비용 0원, 무중단 가동)
- **검증 & 테스트:** Python 3.12 기반 단위 테스트 및 HTML DOM/정적 자산 무결성 자동화
